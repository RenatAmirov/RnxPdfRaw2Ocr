# PDF OCR

Приложение для Windows на C# и WinUI 3. Оно добавляет в скан PDF невидимый текстовый слой, чтобы в документе можно было искать, выделять и копировать текст. Распознавание выполняется локально. Русская и английская модели Tesseract входят в проект.

## Использование

1. Нажмите **Выбрать PDF** и откройте скан.
2. Выберите язык текста. По умолчанию включены русский и английский.
3. Нажмите **Распознать и сохранить…** и укажите путь для копии. Приложение предлагает имя с суффиксом `_OCR.pdf`.
4. Нажмите **Открыть PDF**, чтобы проверить результат в программе просмотра по умолчанию.

Приложение рассчитано на PDF без текстового слоя. Для документа, защищённого паролем, используйте копию, которая открывается без пароля.

## Сборка и запуск

Нужна Windows 10 версии 2004 или новее либо Windows 11, x64. Для сборки из исходников требуется .NET 10 SDK. Для работы нативных библиотек Tesseract на компьютере нужен [Microsoft Visual C++ Redistributable x64](https://aka.ms/vs/17/release/vc_redist.x64.exe).

```powershell
dotnet run -c Release
```

Чтобы собрать папку для запуска на другом компьютере без установки .NET и Windows App Runtime, выполните команду ниже. Запускайте `RnxPdfRaw2Ocr.exe` из папки `bin\publish` вместе с остальными файлами сборки.

```powershell
dotnet publish -c Release --self-contained true -o bin\publish
```

## Реализация

PDFium отрисовывает страницы для Tesseract. Tesseract создаёт PDF только с текстом. PDFsharp добавляет этот слой в копию документа с учётом координат, обрезки и поворота страницы. Исходные изображения остаются в PDF без повторного растрирования.

Модели взяты из [tessdata_fast 4.1.0](https://github.com/tesseract-ocr/tessdata_fast/tree/4.1.0). Шрифт текстового слоя взят из [tessconfigs](https://github.com/tesseract-ocr/tessconfigs/blob/main/pdf.ttf).
